# 图标 / Icon

按用户选择，直接使用本模组的金纹红地毯材质作为图标：
`src/main/resources/assets/overprotocol/textures/block/ceremonial_carpet.png`。
`overprotocol-icon.png` 和 `src/main/resources/logo.png` 与该原贴图逐字节相同。

The icon uses the mod's existing golden-patterned red carpet texture unchanged.
Both the branding copy and the Mods-menu logo are byte-for-byte copies of that texture.
